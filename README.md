# Palette Lab · Ainvest 配色实验台

版本：0.11.0。「自由看板」提供统一的少量 / 大量数据对比模板（25 种图表、50 个模块），覆盖 Vis Lab 全部 25 种公开图表样式；原看板在「自由布局」中保留。支持模块排序、隐藏恢复和 1–5 列布局，两种布局独立保存。

可直接用浏览器打开 `preview.html`，无需安装环境。现有预览、HSB 和 HEX 调色支持离线；新增 Color.js OKLCH 选色器首次加载需要联网。此文件由源码生成，修改后执行 `npm run build:preview` 更新。方案自动保存在当前浏览器，不提供跨设备同步。

## GitHub Pages 发布

仓库内已提供 `.github/workflows/pages.yml`。将代码推送到 `main`，并在仓库 **Settings → Pages → Source** 选择 **GitHub Actions** 后，会验证代码并将 `dist/` 发布为完整交互网页。后续推送自动更新。

页面和资源均使用相对路径，支持 GitHub Pages 的仓库子路径。财报分析、Aime 对话、自由看板及色板导入、调整等操作直接在浏览器运行，无需后端；各使用者的方案保存在自己的浏览器中。OKLCH 第三方选择器需要联网，加载失败时保留 HSB / HEX 调色。

## Aime 手机预览

部署完成后访问 `aime.html`，例如 `https://xin-deep.github.io/ainvest-chart-color-lab/aime.html`。以 Pages 设置页实际提供的网址为准。手机入口复用工作台的图表和配色逻辑，默认进入 Aime 并收起颜色面板；顶部可切换浅深色、分享和打开调色。支持 `?theme=light` / `?theme=dark`。

实际手机预览隐藏模拟状态栏和底部横条，使用动态视口高度与安全区边距；快捷操作可横向滚动，编辑按钮提供触屏点击区域。默认预览隐藏排序/隐藏等编辑工具，点击「调色」后显示；点击图表标题可打开该模块设置。桌面普通工作台仍保留 440px 手机模拟页面。

在工作台 Aime 场景点击「分享手机预览」，复制到手机浏览器，可以还原当前 A/B 色板、当前主题、Aime 模块及全局线宽/纹理。配置放在 URL 的 fragment 中，不需要后端；这是分享当时的快照，后续编辑请重新生成。链接可能较长，请完整复制；不适合直接生成二维码。大型方案或不保留长链接的聊天软件，请使用原有「完整实验 JSON」导出与导入。离线 preview.html 不生成在线链接，需使用已部署的网址。

首次发布：必须先将源码展开到仓库根目录，确保 `.github/workflows/pages.yml` 和 `dist/index.html` 是实际仓库文件，而非仅存在于 ZIP 中。仓库管理员在 Settings → Pages 将 Source 设为 GitHub Actions 后，将代码合并到 main；Actions 成功后显示在线地址。未开启 Pages 时，代码验证仍可运行，但发布会失败并提示管理员配置 Pages。

## 本地运行

需要 Node.js 18+，没有依赖安装步骤。

```sh
npm run dev
```

访问 http://127.0.0.1:4317 。也可以用任何静态服务器托管 `dist/`。因为使用原生 ES modules，请通过 HTTP 访问，不要直接以 file:// 打开 HTML。

```sh
npm run check
npm test
```

## 已提供的框架功能

- 界面仅分左侧贴边预览与右侧统一工作台；左侧没有工具栏、外边距、标题或底栏。
- 单层场景 Tab 位于右侧工作台：财报分析、Aime 对话、自由看板；主题、A/B、色板方案 tab 和保存统一放在右侧。
- 财报页按最新 1919 × 1857 参考图重建，产品导航保持原有矢量外观，内容区改用独立 HTML/CSS 布局与 SVG 图表，自动铺满预览宽度，纵向滚动查看；默认高密度并支持低密度切换，可追加共享图表组件。
- 产品页面包含顶部导航、左侧工具导航和右侧 Watchlist；沿用新参考的 Symbol/Name 搜索、Log In、93% Off，不再显示旧版股票信息条或 Download。品牌色不随图表分类色修改。
- 内容区最大宽度 1560px；模块间距 12px，卡片间距与标题到卡片间距 6px，卡片内边距 8px；模块和卡片标题统一 12px / 600。筛选工具与标题同一行，文字不随整页缩放。
- 财报内容包括 Volume Profile / EPS、技术与投资评分雷达图、收入成本桑基图、资产负债趋势与瀑布图、业务和地区收入环形图、股息分析。图表可点击定位颜色，编辑、撤销及 A/B 切换保留阅读位置。
- 右侧调色面板（桌面 280px / 中屏 260px），可折叠并记住状态；收起后只保留小型浮动展开按钮。分类、涨跌、界面色独立编辑，浅深主题分别存储。
- 颜色编辑器默认隐藏，点击颜色后展开，嵌入 Color.js OKLCH 数值和滑杆调色，保留 HEX、RGB、HSL 输入、撤销和重做；联网加载失败时回退到 HSB。
- 共享模块按图表能力提供数据线宽（默认、0.5–8px）与填充纹理（无、斜线、交叉线、圆点），配置随模块保存。
- OKLCH 按 CSS Color 4 的 D65 矩阵换算，显示明度、彩度、色相与数值有效性；无彩色色相无定义，不用固定 C 上限判定配色质量。
- 「色值检验」支持 OKLCH 分布、ΔE_OK×100 与 Machado 色觉缺陷模拟、WCAG 对比度；ΔE 阈值为可调筛查参考，图形默认参考 3:1，可选择背景和透明度。
- A/B 原位切换：A 为冻结基线，B 为候选修改。
- 上传或拖入 JSON，粘贴 JSON、颜色数组、CSS 变量、色值；先解析预览，再应用。
- 导入已有研究中的常见 JSON 结构，多组颜色在应用前单独选择。
- 保留 Ainvest 原始色板；导入的新色板自动新增并选中 tab，直接点击切换预览，导入前可命名，之后可通过「重命名」修改。
- 切换色板前自动保留修改草稿；支持本地保存候选方案；方案 tab 可删除，并可撤销删除。
- 浏览器本地自动保存；文件仅在浏览器中解析。没有团队云端同步。

「自由看板」支持全部 25 种公开样式：柱状图 3 种、堆叠柱 3 种、折线图 4 种、折柱组合 2 种、行业市值排名 1 种、饼环图 2 种、雷达图 3 种、矩形树图 3 种、桑基图 1 种、弦图 1 种、瀑布图 2 种；固定 Ainvest / PC / 紧凑，支持整行、两列、三列布局与单模块整行占位，模块高度、数据项数、系列数、标签设置，以及添加、复制、移除。双击图形定位色板颜色；A/B、主题和调色共用现有工作台。模块配置随完整实验 JSON 导入导出。旧版 6 类看板首次升级自动补入缺失样式并保留已有模块参数；升级后主动移除的模块不会在刷新后恢复。参数控件依图表能力显示，雷达维度限制 3–6；固定拓扑的桑基图、瀑布图不提供无效的项数设置。数据为固定演示数据。股票详情、颜色检查报告后续继续。财报页的文字、结构、坐标、构成比例和曲线按最新「财报分析.png」重建；未标注的数据由图形几何估计，不是实时财务数据。两侧下半段的长图拼接黑底不属于产品内容，不纳入还原。新参考只提供浅色，财报深色是实验环境；分类色在黑白环境下保持用户确认的同一组 7 色。

## 数据约定

`schemaVersion: 1` 的色板包含 `name`、`source`、`availableThemes`、`themes.light`、`themes.dark`。每个主题包含 `categorical`、`semantic`、`surface`；颜色项使用 `id`、`name`、`hex`。

`surface` 顺序：页面背景、卡片背景、主要文字、次要文字、分隔线、网格线。`semantic` 顺序：上涨、下跌。

完整实验文件使用 `kind: "palette-lab-session"`，保存 `toolVersion`、场景、主题、基线、候选色板和 `customBoard` 模块配置。浏览器最多保留 30 个本地方案。

默认界面色是本工具的实验环境，不是竞品实测界面 token。

## 后续扩展

`dist/app.js` 负责工具界面与状态；`dist/lib/` 负责颜色转换和导入；`dist/data/presets.js` 管理参考色板；`dist/scenes/financial.js` 渲染财报；`dist/data/financial-reference.js` 保存从用户图片描取的折线几何。

`/financial-review.html` 提供脱离工具外壳的原尺寸对照页，可用 `?theme=dark` 检查深色试验环境。未来场景应挂载到 `#preview-canvas`，从当前色板按主题和角色取色；不要直接按相同 HEX 全局替换。

## Git 与部署

`dist/` 是可直接托管的静态网站目录，适用于 GitHub Pages 等静态托管。无构建步骤。发布时分别记录工具版本和 JSON 的 schemaVersion，并在 CHANGELOG.md 中记录变更。

`.openai/hosting.json` 是 Sites 托管配置。若迁移到 GitHub Pages，可忽略该配置。源码、版本记录与实验 JSON 均可纳入 Git；浏览器中的个人试验不会自动提交到仓库。

## Vis Lab 组件来源与重建

来源：https://github.com/fatmoney9/vis-lab ，固定提交 `927996825adb7e10d719357760fcbefa1392f5e0`。`dist/vendor/vis-lab/source/` 保留原始源码；图表在 Shadow DOM 内运行，避免组件样式影响财报页与颜色工作台。构建适配器将 token JSON、图标内联，并把取色器连接到当前实验色板；超过当前色板数量的分项使用中性色。

运行和部署使用已提交的 `dist/vendor/vis-lab.bundle.js`，不需要联网或安装依赖。只有重建上游组件时才需要：

```sh
npm install
npm run build:vis
npm run build:preview
```

构建依赖固定 D3 7.9.0 和 esbuild 0.25.9；锁文件记录传递依赖。普通页面修改只需 `npm run build:preview`。

### 图表外观一致性（0.4.2）

图表默认数据量使用 Vis Lab 的 `defaultDensityCountOf`，不再统一设置 22 项。「紧凑」仅表示原始 `data-density=compact` 版式，独立于数据项数。默认高度交由组件自身 token 决定；坐标轴、图例和网格线沿用上游颜色，只有主动修改对应界面色时才覆盖。饼环默认使用原始右侧图例与标签规则。

旧版自动生成的默认数据量与固定高度会升级到原始默认值，已修改的非默认参数保留。基础折线图默认 4 类目，显示 829K / 809K / 950K，第二类目为空值断点。

0.4.3：右侧「看板布局」中的「图表版式」可统一切换 25 种图表的紧凑 / 宽松（默认紧凑），使用 Vis Lab 原始版式 token。修改项数时保持当前阅读锚点，不再返回顶部。

## Aime 对话预览

按用户提供的黑白版参考搭建 440px 移动对话页面，包含分析文字、导航、输入区与五张动态图表。面积折线、连续分红横条、环形图、堆叠柱和分组柱直接调用自由看板的同一 PaletteVisEngine / CHARTS 组件引擎。Aime 只提供业务数据与移动端配置。数据用于截图复现和配色测试，不是实时行情。

右侧添加模块、卡片上的加号、输入区加号均可插入全部 25 类组件，支持复制、移除、参数编辑、浅深色、紧凑/宽松和 A/B。两个场景各自保存模块；完整实验 JSON 新增 aimeBoard，旧文件仍可使用。

## 财报共享组件（0.5.1）

财报中的技术雷达、投资评分雷达、资产负债折柱组合、资产负债瀑布、业务收入环形、地区收入环形、派息率组合和股息收益率折线共 8 张，直接复用自由看板图表引擎。保留财报业务数据，金额和百分比双轴独立格式化，分类主色、天蓝与第七个橙色继续对应原有角色。小尺寸雷达适配原卡片容器；环形中心显示原报表总额，外侧明细按原数据展示，未修正原截图的舍入差额。

EPS 实际/预估点图没有对应的公开组件类型，暂保留原实现。财报桑基的截图数据存在流量舍入差额（例如收入分项合计 109.41B，展示总额 109.42B），无法直接通过共享组件的严格守恒校验；暂保留原实现，不擅自改动金额或增加虚构项目。财报文字、产品导航、Watchlist 与中间滚动方式保持。

## Color.js OKLCH 选色器

点击颜色后延迟加载官方 `<color-picker>`，支持 L/C/h 数值输入和滑杆调节。固定组件版本 `color-elements@0.0.14`，并通过 `?deps=colorjs.io@0.6.1` 固定兼容的 Color.js 依赖，避免自动升级后的色彩空间注册异常。选色同步更新当前 HEX 色板、预览和检验结果，并支持撤销；Color.js 使用自身色彩转换处理 OKLCH。A 原始视图只读。网络不可用时明确提示并保留原 HSB / HEX 编辑器。

已在实际浏览器验证三个调色通道、HEX 与检验实时联动、撤销恢复。第三方组件目前通过 esm.sh 联网加载，未打包进离线文件；加载超时或滑块初始化失败时，原有 HSB / HEX 仍可使用。
